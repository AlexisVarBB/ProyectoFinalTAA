## Instrucciones del Proyecto

### 🔧 Controlador de Versiones

Este proyecto requiere la implementación de un sistema de control de versiones utilizando Git y GitHub. A continuación se detallan los pasos a seguir:

#### Pasos en Equipo (Documentación Conjunta)

1. **GITHUB - Crear cuenta del equipo**
   - Crear una cuenta de GitHub para el equipo
   - Documentar el proceso con screenshots
   - Incluir credenciales de acceso

2. **GITHUB - Crear repositorio**
   - Crear un repositorio en GitHub siguiendo los procedimientos de clase
   - Inicializar el repositorio con archivo README
   - Documentar la configuración y estructura inicial

3. **GITHUB - Crear archivo base del programa**
   - Crear un archivo base en el lenguaje de programación de preferencia del equipo
   - Guardar el archivo en el repositorio
   - Documentar la estructura inicial del código

#### Pasos Individuales (Documentación Personal)

4. **GIT - Descargar e instalar Git**
   - Descargar Git desde https://git-scm.com/
   - Instalar en la computadora personal
   - Documentar el proceso de instalación con screenshots

5. **GIT - Configurar nombre y correo**
   - Ejecutar comando: `git config --global user.name "Tu Nombre"`
   - Ejecutar comando: `git config --global user.email "tu.email@example.com"`
   - Documentar la configuración realizada

6. **GIT - Clonar el repositorio**
   - Clonar el repositorio del equipo localmente
   - Verificar que los archivos se descarguen correctamente
   - Documentar el proceso y ubicación de la carpeta local

## 📋 Requisitos de Documentación

### Formato
- Documento: Word (.docx)
- Entrega: PDF (.pdf)

### Contenido Requerido

#### Documentación Conjunta (Equipo)
- Explicación detallada de cada uno de los primeros 3 pasos
- Screenshots de cada proceso realizado
- Evidencia de la creación de cuenta, repositorio y archivo base
- Cada miembro debe entregar su propia documentación de los pasos en equipo

#### Documentación Individual (Personal)
- Explicación detallada de los pasos 4, 5 y 6
- Screenshots del proceso de instalación de Git
- Screenshots de la configuración de nombre y correo
- Screenshots del clonado del repositorio
- Ruta de carpetas donde se encuentra el repositorio clonado
